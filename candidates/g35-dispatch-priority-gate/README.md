# G35 - dispatch-priority rollout gate

Marketplace interference under a two-stage randomised-saturation experiment.

The pilot readout reports a pooled treated-minus-control lift. It is unbiased for a real quantity -
the direct effect at the pilot's mixed saturation - and it is not the rollout effect, because
couriers are a fixed pool per city-day and priority is largely redistributive.

Research and gates: `research/g35/`.
