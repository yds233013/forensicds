# Correct-table gate (C1)

Every simulation runs on **perfectly clean, fully labelled tables**:
- the parallel run with both scans and the old reading;
- the pre-period check re-measures flagged;
- the post station values;
- the blocks.

There is no ETL, no missing data and no discovery. On those tables, first-order wrong methods remain
wrong (W01/W02/W22 at 11–70 SE_REF; W03/W04/W05/W06 at 4–13).

**The difficulty is statistical, so the gate passes.** The failing gates are the counterexample and
window gates, not data discovery.
